设计理念

回归驾驶本质的 JDM 性能座驾

没有多余的修饰，没有妥协的设计，没有冗余的科技包装。它存在的意义只有一个：为驾驶而生。 它并非为了吸引目光，而是为了带来纯粹的操控体验。RZ-01 代表的是——

驾驶本身，就是答案。

技术规格

⚙️ 布局 FR 前置后驱
🔋 功率 240 ~ 380 匹
⚙️ 变速箱 6MT / 8AT
⚖️ 整备质量 1250 ~ 1350 kg
🏁 驱动 RWD 后驱
🎮 驾驶模式 NORMAL / SPORT / TRACK / DRIFT
🖋️ 理念标语 純粋な運転のために
🎨 配色 夜黑 / 奢华灰 / 冠军白

核心特色

01

后驱轻量化结构

FR 前置后驱布局，整备质量仅 1250~1350kg，推重比超越多数跑车。

02

高转速 / 涡轮性能动力

可选 2.0L 自然吸气（240匹）或 2.4T 涡轮（380匹），红线 7500rpm 以上。

03

机械反馈导向调校

6MT 手动或 8AT 可选，机械液压转向，物理仪表盘，拒绝触屏妥协。

04

DRIFT 漂移模式

专属漂移模式，可独立关闭电子稳定系统，真正的 JDM 纯粹体验。

设计语言

纯粹，是一种态度

RZ-01 的设计语言来自 90 年代 JDM 黄金时代。宽体套件、引擎盖散热孔、巨大的前进气格栅——每一个设计决策都是功能性的。

配色只有三款：夜黑、奢华灰、冠军白。内饰坚持机械仪表盘 + 物理按键。拒绝全触屏，因为我们相信：驾驶者应该能盲操作每一个控制。

日文标语 「純粋な運転のために」（为纯粹的驾驶而生）—— 直接写在设计板上。

设计参考 Pure 90s JDM Spirit
灯语 猫眼 LED + 机械黄光
配色 夜黑 / 奢华灰 / 冠军白
