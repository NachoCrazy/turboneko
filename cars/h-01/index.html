设计理念

游走于现实边界的终极超跑

H-01 并非为日常使用而设计，而是用来定义品牌的极限。 它无需声浪来证明，因为它本身就是卓越的成果。当你坐进驾驶舱的那一刻，所有的参数都变得不再重要——重要的是那种「边界感」。 H-01 代表的是——

速度的终点，不需要解释。

技术规格

⚡ 功率 ~1550 匹
🔩 扭矩 ~1560 N·m
💨 0-100 km/h 2.3 秒
🏁 极速 350+ km/h
⚖️ 整备质量 ~1380 kg
🏗️ 车架 碳纤维单体壳
🔋 电池 9.8 kWh 高功率
🎮 驾驶模式 STEALTH / PERFORMANCE / TRACK / PHANTOM

核心特色

01

中置高性能混动架构

V8 双涡轮 + 三电机混动，中置引擎布局，42:58 前后重量分配。

02

极致空气动力设计

主动尾翼、底部分流板、后扩散器联动，200km/h 下压力超过 900kg。

03

赛道级性能输出

1550 匹综合功率，1380kg 整备质量，推重比超过 1.12:1，进入 F1 领域。

04

碳纤维单体壳车架

全碳纤维单体壳，扭转刚度 65000N·m/deg，安全等级超越 FIA 要求。

设计语言

静止时是雕塑，移动时是幻影

H-01 的设计没有一丝多余。每一根线条都是空气动力学计算的结果，每一处曲面都在为下压力服务。

中置引擎布局带来了极致的比例：驾驶舱前移、后轮拱夸张隆起、座舱紧凑如战斗机。 四种驾驶模式（STEALTH / PERFORMANCE / TRACK / PHANTOM）各自对应不同的空力配置——从隐藏式的 STEALTH 模式，到极限下压力的 PHANTOM 模式。

品牌理念：「NEKO 不只是速度的象征，更是一种精神的状态——敏捷、纯粹、灵动。它既存在于现实中，只为突破极限而生。」
